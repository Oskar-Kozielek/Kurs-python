# Zadanie 3.1

```python
x = 2; y = 3;
if (x > y):
    result = x;
else:
    result = y;
```

To jest poprawne składniowo. Średniki oraz nawiasy w if niepotrzebne ale dozwolone

```python
for i in "axby": if ord(i) < 100: print (i)
```

Niepoprawne w Pythonie po dwukropku w instrukcji for można umieścić prostą instrukcję w tym samym wierszu, ale nie można w ten sposób zagnieździć kolejnej instrukcji złożonej if.

```python
for i in "axby": print (ord(i) if ord(i) < 100 else i)
```

To jest poprawne pokazuje użycie wyrażenia warunkowego "a" if "warunek" else "b".
